# Reglas de Diseño UI/UX para CodeBridge

Cuando generes código de frontend (HTML, CSS, React, etc.), DEBES seguir estas reglas estrictamente:

1. **Estética Premium**: El diseño debe ser moderno, limpio y profesional.
2. **Paletas de Colores Curadas**: No uses colores genéricos (red, blue, green). Usa colores HSL o paletas de Tailwind con contrastes adecuados (ej. Slate-900 para fondos oscuros, Emerald-500 para acentos).
3. **Micro-animaciones**: Todos los elementos interactivos (botones, enlaces, tarjetas) deben tener transiciones suaves (ej. `transition-all duration-300`) y estados `:hover` o `:active`.
4. **Glassmorphism / Sombras**: Usa sombras suaves (`shadow-lg`, `shadow-xl`) y efectos de desenfoque de fondo (`backdrop-blur`) donde aplique para dar profundidad.
5. **Tipografía Moderna**: Asume el uso de fuentes sans-serif limpias como Inter, Roboto o Outfit.
6. **Responsividad**: Todo el diseño debe ser *mobile-first* y adaptarse a pantallas más grandes.
